# 当前实现与后续路线

更新：2026-08-20

## 已交付的首个垂直切片

当前仓库可以使用 Swift Package Manager 构建原生 macOS App、探针 CLI 和无测试框架自检 CLI。App 先显示 SwiftUI 外壳，再并发加载 Provider；自动刷新可选择 1、2、5 或 10 秒，并为动态通道保留最多 600 个不同时间戳的内存历史点。

首版包含 10 个 Provider：系统、电池、公开热压力、只读 SMC、显示、存储、SPU 存在性、SPU 实时报告、上盖角度和实验硬件能力。数据模型始终保留稳定 ID、来源、单位、原始/派生类别、能力等级、状态、时间戳和限制说明。

## 本机验证结果

- Swift 6.3.3 Command Line Tools 构建通过；
- `sensorlab-selftest` 验证 Provider 唯一性、真实可用数量、范围、有限值、隐私字段和 JSON/CSV 有效性；
- App 打包、Info.plist 校验和 ad-hoc 签名通过；
- GitHub Actions 使用 `macos-26` 执行格式、构建、XCTest、portable 自检与 App Bundle 验证；
- SwiftUI 的 Overview、Raw Sensors、Experiments、Diagnostics 四页已做可访问性树回归；
- 电池、SMC 温度/风扇/功耗、上盖角度和环境光在本机得到真实读数；
- SPU 环境光单进程连续 20 次和双进程各连续 20 次读取均成功；
- SPU 打开错误现在区分权限拒绝和临时争用；短暂缺报最多保留 12 秒的最近成功样本，且不伪造新时间戳；
- SPU 加速度计/陀螺仪在系统不发布报告时安全降级，没有写入驱动属性；
- Xcode 首次组件初始化已完成，本机 15 项 XCTest 全部通过；GitHub Actions 继续提供独立 Xcode 环境复验。
- 自动采样支持暂停/恢复和内存历史清空；连续 CSV 记录包含原始值与格式化值，逐批同步并有 50 MB 硬上限。
- Light Meter 提供原始值滚动统计和可选单点 Estimated lux；Lid Protractor 提供本地参考角度与相对变化。
- Computer Use 回归验证了暂停/恢复、校准输入、派生通道、上盖参考交互和 Trackpad Scale 未误解锁；临时测试校准均已清除。

真实数值不写入仓库文档，以免把一次性机器状态误当成固定测试结论。

## 安全与隐私不变量

1. 不以 root 运行整个 App；
2. 不调用 sudo，不修改 Apple SPU 驱动属性；
3. SMC 目标中不存在写 key 或风扇控制方法；
4. 仅查询固定白名单的电池字段；
5. 不采集序列号、硬件 UUID、主机名、用户名、网络标识、位置、进程列表或录音；
6. 只有用户主动使用导出或连续记录按钮时，数据才会写入用户选择的 JSON/CSV 文件；
7. 未校准的环境光、姿态或称重值不会包装为计量结果。
