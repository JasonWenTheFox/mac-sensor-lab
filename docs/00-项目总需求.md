# 00 项目总需求

## 产品定义

构建一个接近 Android “Sensors Toolbox” 思路、但尊重 macOS 硬件与 API 现实的原生开源 App。

产品按三层逐步建立能力：

1. **事实层**：尽可能忠实地展示原始传感器通道，即使数值尚未对普通用户友好。
2. **展示层**：将原始值组织为有来源、单位、时间、访问级别、兼容性证据和就绪状态的人类可理解卡片、趋势与导出。
3. **解释/测量层**：在算法、校准和误差边界透明的前提下，把信号转成姿态、角度、运动变化、重量、光照等级或声学指标等对现实世界的有界解释。

## 核心原则

- UI 秒开：导航、占位、上次状态说明先出现，传感器后台加载。
- 事实优先：显示来源、单位、采样率、权限、校准与可信度。
- 渐进增强：先可靠 MVP，再逐个接入高风险或私有接口。
- 失败隔离：单一 Provider 失败不影响整个 App。
- 开源可审计：代码来源与许可证清楚，避免不可解释的二进制和无许可复制。
- 隐私最小化：默认本地处理，不上传，不记录设备唯一标识。

## 目标用户

- 想了解 Mac 隐藏硬件能力的普通用户；
- 开发者、创客、学生和实验爱好者；
- 需要观察趋势、导出原始数据或验证硬件状态的用户；
- 对触摸板、机身运动、开合角、热状态和功耗感兴趣的 Mac 用户。

## 功能版图

### 系统与电源

- 芯片架构、核心数、内存容量、系统版本；
- 非唯一 Mac 机型类别、Apple SoC 系列、CPU 拓扑、统一内存布局、Metal GPU 与 Touch ID 能力；
- 汇总 CPU 利用率、系统负载、Mach 内存页分类与交换空间，不采集进程列表；
- 电池电量、充放电状态、电源来源、循环计数与明确标注的容量派生比例；
- 系统热压力、低电量模式和可公开获得的能耗信息；
- 显示器数量、分辨率、刷新率和亮度能力状态；
- 文件系统容量与可用空间；
- 活跃网络接口概览。

### 隐藏与实验性传感器

- 三轴加速度、三轴角速度、姿态和振动；
- 环境光原始值与可选校准；
- 屏幕开合角与角速度；
- Force Touch 触点、压力、面积与实验性称重；
- SMC/HID 温度、风扇、电压、电流和功耗；
- 麦克风 dBFS、频谱与经校准的估算 dBA；
- 网络定位（明确不是原始 GPS）。

### 派生实验

- 水平仪、电子量角器、姿态仪；
- 振动记录与冲击峰值；
- 触摸板电子秤和多点校准；
- 光照相对变化与多点 lux 校准；
- 声学趋势和 A 计权实验；
- CSV/JSON 记录与导出。

## 明确不做

- 不控制风扇、键盘背光、扬声器或系统功耗策略；
- 不把整个 App 以 root 运行；
- 不绕过 TCC、Gatekeeper、Sandbox 或系统权限；
- 不把估算结果宣传为专业计量；
- 不承诺所有 Mac 型号和未来 macOS 版本都支持私有接口；
- 首版不以 Mac App Store 为发布目标。
